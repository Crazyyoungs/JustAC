## [Unreleased]

### Added

- Nameplate overlay resource bar: the optional resource bar from the standard queue is now available on the nameplate overlay too - your primary resource (mana, energy, rage, and so on) plus, for specs that use one, a segmented secondary point resource (combo points, runes, chi, holy power, soul shards, arcane charges, essence) - stacked beyond the overlay health bars and colored by resource type. Enable it under Nameplate Overlay options; it needs the overlay health bars turned on.

### Improved

- Nameplate overlay health bars now match the standard queue's styling - a neutral darkened background behind the fill and a subtle sheen - instead of a flat red background, so the two displays read consistently.
